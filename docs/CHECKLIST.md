# 직접 확인 목록 (맥)

상태: 2026-10-14 기능 기준으로 갱신(유료 표시·회의 중 조용히·지켜볼 낱말·내 기록 내보내기·끈 출처 빼기·분야 지면·읽기 실패 안내 추가).

자동 시험과 앱 스냅샷으로는 확인할 수 없는 것들입니다. 이 Mac 에는 화면 캡처·자동 조작 권한이 없고, 일부는 시스템 연동(위젯·단축어·Spotlight·서비스 메뉴)이라 사람이 직접 눌러 봐야 합니다. 15분 안팎이면 끝납니다.

결과는 항목 번호와 함께 "됨 / 안 됨(무엇이 어떻게)"만 알려 주시면 됩니다.

## 1. 기본 흐름 (3분)
| 번호 | 할 일 | 기대 |
|---|---|---|
| 1-1 | 상단바 Dropcap 아이콘 클릭 | 'Dropcap' 머리, 첫 소식 큰 사진 카드 + 사진 카드 목록, 분야 칩 줄 |
| 1-2 | 목록에서 기사 하나 클릭 | 읽기 창이 열리고 1~2초 안에 본문(번역 기사는 위에서부터 한국어로 바뀜). 불러오는 동안에도 요약이 먼저 보임 |
| 1-3 | GeekNews·블로터·SBS 기사 하나씩 열기 | 모두 본문이 뜸(예전엔 GeekNews 가 16초 뒤 실패) |
| 1-4 | 목록에서 ↑↓(또는 J/K) → ⏎ | 선택 테두리가 움직이고 ⏎ 로 열림. S 저장, O 브라우저, M 읽음 |
| 1-5 | 읽기 창에서 J/K, Esc | 다음·이전 기사로 바뀌고 Esc 로 닫힘 |
| 1-6 | 정렬 단추 → 중요순·출처별 | 단추에 정렬 이름이 보이고 순서가 바뀜, 출처별은 이름표 |

## 2. 읽기 창 (2분)
| 번호 | 할 일 | 기대 |
|---|---|---|
| 2-1 | 도구 막대 '모양'(Aa) → 종이 · 명조 · 줄 간격 넓게 | 바로 바뀌고 다음 기사에도 유지 |
| 2-2 | ⌘F → 낱말 입력 → ⌘G | 일치하는 곳 강조, 다음으로 이동 |
| 2-3 | 문단에 마우스 → 왼쪽 가위 단추 클릭 | 스크랩되고 폴더·메모 팝오버 |
| 2-4 | 기사 속 사진에 마우스 → 오른쪽 위 단추(번역·복사·저장) | 영어 글자 있는 사진은 번역 창, 복사·저장 동작 |
| 2-5 | 도구 막대 링크 단추(⌘⇧C) | "기사 주소를 복사했어요" |
| 2-6 | 조선일보 기사 하나 열기 | 1초 안팎에 본문(페이지에 실린 본문 자료로 읽음) |
| 2-7 | WSJ·NYT 처럼 유료 출처 기사 열기 | 카드·목록에 자물쇠, 막히면 '같은 소식을 무료로 읽기' 상자에 다른 곳 보도 |
| 2-8 | BBC 영상 기사(`/news/videos/`) 열기 | "본문 글이 거의 없는 기사입니다(영상·사진 기사 등)" 안내 + 원문 열기 |

## 3. 분야·알림 (2분)
| 번호 | 할 일 | 기대 |
|---|---|---|
| 3-1 | 설정 › 분야 → 분야 고르기 다시 열기 | 유리 카드(분야색 + 오늘의 사진)로 12개 분야 |
| 3-2 | 분야 하나 '즉시'↔'묶음'↔'매거진만' 바꾸기 | 바로 저장(창을 닫았다 열어도 유지) |
| 3-3 | 설정 › 일반 › Pretendard 끄기 | 열려 있는 상단바·매거진·읽기 창 글꼴이 **바로** 바뀜 |
| 3-4 | 설정 › 거르기 → '꼭 알림'에 지금 목록에 있는 낱말 입력 | Return 없이 잠시 뒤 저장, 목록의 그 기사에 ★ |
| 3-5 | 설정 › 일반 › 알림 미리 보기 | 물방울이 맺혀 떨어지고 카드가 됨, 물이 끝까지 빠지고 사라짐 |
| 3-6 | 목록 기사 오른쪽 클릭 → 이 출처 숨기기 | 목록·매거진에서 바로 빠짐(설정에서 되돌리기) |
| 3-7 | 설정 › 구독에서 출처 하나 끄기 | 그 출처 글이 목록·안 읽음 수·매거진·스토리·검색에서 바로 빠짐 |
| 3-8 | 설정 › 거르기 › '지켜볼 낱말'에 지금 목록에 있는 회사 이름 | 그 기사 줄에 눈 아이콘(★ 와 겹치면 ★) |
| 3-9 | 설정 › 일반 › 회의 중 조용히 › '전체 화면 앱을 쓰는 중' 켜고 다른 앱을 전체 화면으로 | 그동안 물방울 없이 '안 읽음'에 쌓이고 상단바 머리에 까닭 아이콘 |
| 3-10 | 설정 › 일반 › 내 기록 내보내기 → 같은 파일 가져오기 → 마지막 가져오기 되돌리기 | 파일이 생기고, 가져오기는 "새로 더할 것이 없었습니다", 되돌리기 단추가 동작 |

## 4. 매거진 (2분)
| 번호 | 할 일 | 기대 |
|---|---|---|
| 4-1 | ⌥⌘M | 오늘 호, 머리 아래 "소식 N건 중 M건 실음", 분야 지면이 유리 띠로 시작 |
| 4-2 | 오늘 호의 분야 칩(예: IT) 누르기 | 왼쪽 목록도 IT 로 바뀌고 제목이 'IT', 그 분야 건수·출처 수, '전체' 칩 없음 |
| 4-3 | 왼쪽 'AI' | AI 하위 칩(모델·제품·연구…·기타), 칩 숫자의 합 = 실린 수 |
| 4-4 | 왼쪽 '이번 주' | 제목 "이번 주 · (이번 주 일요일)–(오늘)", 지난 주간 범위와 겹치지 않음 |
| 4-5 | 왼쪽 지난 호 목록 | 최신 날짜부터 차례대로, 주간은 그 주 토요일 호 바로 위, 기사 적은 호는 흐리게 |
| 4-6 | 스토리 → 하나 열기 → '이 스토리 팔로우' | 분야 표시가 묶인 보도 다수 분야, 팔로우 표시, 해외·국내 두 칸(둘 다 있을 때) |
| 4-7 | 오늘 호 대표 기사를 모두 읽기 | 진행률이 차고 '오늘 호를 다 읽었어요' |
| 4-8 | 검색(⌘F)을 빈 채로 | 지켜볼 낱말·최근 검색 칩과 도움말 |
| 4-9 | ⌘[ / ⌘] | 지면 넘기기 |

## 5. 시스템 연동 (3분) — 자동으로 확인 못 한 것
| 번호 | 할 일 | 기대 |
|---|---|---|
| 5-1 | 바탕화면 오른쪽 클릭 → 위젯 편집 → 'Dropcap' 검색 | 오늘의 표지·안 읽은 수·최신 3건 위젯이 보이고, 누르면 그 기사가 읽기 창으로 |
| 5-2 | 단축어 앱 → 새 단축어 → 'Dropcap' 검색 | '최신 소식 가져오기'·'주소를 나중에 읽기로 저장'·'매거진 열기' 동작 |
| 5-3 | Spotlight(⌘Space)에 저장한 기사 제목 일부 입력 | 저장·스크랩한 기사가 결과에 나오고 누르면 읽기 창 |
| 5-4 | Safari 에서 기사 주소를 선택 → 오른쪽 클릭 → 서비스 › 'Dropcap 에 저장' | 저장 확인 창 → 저장 목록에 추가 |
| 5-5 | 설정 › 스크랩북의 북마클릿을 Safari 즐겨찾기에 추가 → 기사에서 누름 | 저장 확인 창 → 저장 목록 |
| 5-6 | 설정 › 스크랩북 › 노트 폴더 지정 → 문단 스크랩 | 그 폴더에 `<폴더 이름>.md` 가 생기고 갱신 |
| 5-7 | 설정 › 구독 › OPML 내보내기 → 가져오기 | 파일이 생기고, 가져오면 출처가 하나씩 확인되며 추가 |

## 6. 시간이 걸리는 것 (하루 쓰면서)
- 묶음 분야가 정한 시각(기본 18시) 뒤 첫 확인에 "경제 N건" 한 방울로 오는지, 매거진 그 분야 지면 위에 저녁 정리(Apple Intelligence 가 켜진 Mac)가 생기는지
- 지켜볼 낱말에 걸린 소식이 아침 브리핑 시각에 "오늘 ○○ 소식 N건" 한 방울로 정리되는지(누르면 매거진 검색)
- 캘린더 일정 중 조용히를 켰다면 회의 시간에 물방울이 오지 않는지
- 즉시 분야는 여러 곳이 다룬 소식만 물방울로 오는지(하루 3번 넘으면 고였다가 묶음으로)
- 팔로우한 스토리에 새 보도가 붙으면 알림이 오는지
- 방해 금지 시간에는 알림 없이 안 읽음에만 쌓이는지
