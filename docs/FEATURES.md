# Dropcap 기능 목록

세 판(맥 · 윈도우 · 리눅스)이 갖추는 기능을 한 줄씩 적었습니다. 번호(C-16 등)는 코드 주석과 시험이 가리키는 번호입니다.
동작·문구·수치의 기준은 맥 코드이고, 운영체제 한계로 다르게 한 것은 맨 아래에 있습니다.

- 상태: `✓` 됨 · `~ 확인 필요` 코드·시험은 됐고 그 운영체제에서 눈으로 확인할 것이 남음 · `~ …` 다른 방법으로 대신함 · `⊘` 운영체제 한계로 못 함 · `☐` 아직
- 2026-10-20 현행화: 10-14 이후 들어온 기능을 행으로 넣고, 세 판 칸은 git 기록과 코드로 채움.
