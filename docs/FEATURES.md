# Dropcap 기능 목록 (세 앱 공통 기준)

맥(Swift) · 윈도우(C# WinUI 3) · 리눅스(Rust GTK4) 앱은 **이 목록의 모든 항목**을 구현합니다. 번호마다 "됨"의 기준이 있습니다.

- 상태: `✓` 됨 · `☐` 아직 · `⊘` 운영체제 한계로 불가(반드시 **사유와 대신 한 것**을 적음) · `~` 대체 구현(무엇으로 대신했는지 적음)
- 참고 열은 맥 구현 위치(`mac/Sources/Dropcap/...`). 동작·문구·수치는 맥과 같게 맞춥니다.
- 작업자는 끝낸 항목의 번호로 보고합니다. 빈칸(☐)이 남은 단계는 완료로 받지 않습니다.
- 수치(시간·크기·개수)는 이 문서와 맥 코드가 기준입니다. 다르게 하려면 먼저 관리자에게 결정을 요청합니다.
