# Dropcap 기능 목록

세 판(맥 · 윈도우 · 리눅스)이 갖추는 기능을 한 줄씩 적었습니다. 번호(C-16 등)는 코드 주석과 시험이 가리키는 번호입니다.
동작·문구·수치의 기준은 맥 코드이고, 운영체제 한계로 다르게 한 것은 맨 아래에 있습니다.

## C. 뉴스 수집·판단 (핵심)
- **C-01** shared/sources.json 을 읽어 기본 출처 사용
- **C-02** RSS 2.0 · Atom · RDF 해석
- **C-03** 사이트맵 출처: 정규식에 맞는 주소만, 새 글은 페이지에서 og:title·description 으로 제목·요약 채움
- **C-04** 대표 사진: media:thumbnail → media:content → media:group 썸네일 → 그림 enclosure → 본문 첫 <img>
- **C-05** Content-Encoding 없이 온 gzip 본문 풀기
- **C-06** 조건부 요청
- **C-07** 일시 오류 재시도: 429·5xx 한 번, YouTube 피드의 404 는 두 번
- **C-08** 본 글 기억
- **C-09** 날짜가 3일보다 오래된 글은 새 글로 치지 않음
- **C-10** "AI 글만" 출처: aiPattern이 제목+요약에 맞을 때만
- **C-11** 확인 간격 2·5·10·15·30분
- **C-12** 앱은 하나만 실행
- **C-13** 상태 저장: 원자적 쓰기, 0.5초 안의 저장 요청은 하나로 묶어 뒤 스레드에서 쓰고 끝낼 때·잠들기 전에는 바로 씀, 실행마다 첫 쓰기 전 .bak 백업,…
- **C-14** 낱말 거르기: 꼭 알림·알리지 않음
- **C-15** 같은 소식 묶기: 원제목 낱말 겹침, 한국어 제목 낱말 겹침, 영어 제목의 뜻
- **C-16** AI 분야 안의 하위 분류
- **C-17** 글 종류: 기사·영상·논문·릴리스·커뮤니티·팟캐스트
- **C-18** 관심사: 연 기사의 분야·출처 횟수 → 가중치
- **C-19** 방해 금지 시간
- **C-20** 알림 잠시 끄기: 1시간·3시간·내일 아침 8시까지·다시 켜기
- **C-21** 아침 브리핑: 매일 정한 시각~정오 전에 지난 24시간 소식이 있으면 브리핑 알림 → 매거진
- **C-22** 최근 소식 300건, 안 읽은 수
- **C-23** 읽음 기록, 3000개 넘으면 오래된 것부터 2000개만 남김
- **C-24** 저장: 저장하면 번역까지 미리 준비해 오프라인 보관, 캐시 정리에서 제외
- **C-25** 출처 단위로 알림을 끈 곳은 매거진에만 싣고 목록·알림에는 넣지 않음

## G. 일반 뉴스 분야·알림 정책
- **G-01** 분야 체계: shared/categories.json
- **G-02** 기사의 분야: 출처 section 1순위
- **G-03** 첫 실행 관심 분야 고르기: 분야 유리 카드, 주요 뉴스 스위치, '더 보기'
- **G-04** 분야별 알림 모드: 즉시 / 묶음 / 매거진만
- **G-05** 즉시 모드에서도 물방울은 ① 같은 이야기를 국내 3곳 이상 또는 해외 2곳 이상이 보도 ② 공식 발표 등급 ③ ★꼭 알림 낱말 ④ 팔로우한 스토리
- **G-06** 하루 상한: 분야별 3번·전체 10번
- **G-07** 묶음: 분야마다 정한 시각 뒤 첫 확인 때 고인 소식을 한 방울, 누르면 매거진의 그 분야 지면
- **G-08** 같은 이야기는 한 번만
- **G-09** 분야 칩 줄: 상단바 목록·매거진
- **G-10** 매거진 분야 지면: 주요 뉴스 → 고른 분야 → 고르지 않은 분야 → 그 밖의 소식
- **G-11** 바로 줄이기: 이 출처 숨기기 / 이 분야 덜 받기 / 이 낱말 알리지 않기
- **G-12** 해외·국내 나란히: 스토리 상세에 '해외에서는 N곳 / 국내에서는 N곳' 두 칸, 매거진 카드에 두 줄
- **G-13** 설정 '분야' 탭: 고른 분야마다 모드·묶음 시각·하루 상한·켜진 출처 수, 전체 상한·문턱, 숨긴 출처 되돌리기, 관심 분야 다시 고르기
- **G-14** 유료 기사 표시: shared/sources.json 의 paywall, 없으면 주소 도메인, 그래도 없으면 사용자가 연 기사의 본문 추리기 결과를 출처별로…
- **G-15** 같은 소식을 무료로 읽기: 유료·자주 막히는 곳의 기사를 열거나, 본문을 못 열었거나 맛보기만 나오면 읽기 창 머리에 '같은 소식을 무료로 읽기:…

## S. 안전 (피드에서 온 주소는 믿지 않음)
- **S-01** 공개 http만: localhost·.localhost·.local·.internal·.lan·.home.arpa·.arpa·점 없는 이름 거절
- **S-02** 요청 전 이름을 실제 IP 로 풀어 하나라도 내부망이면 거절
- **S-03** 실제로 접속한 IP 를 다시 확인, 확인 못 하면 막음
- **S-04** 리다이렉트도 같은 검사
- **S-05** 본문 추출용 웹 보기 안의 이동도 같은 검사
- **S-06** 알림 때 미리 받기는 사이트 스크립트를 실행하지 않음
- **S-07** 사진은 안전 검사를 거치는 로더로만: 8MB 까지, 최대 1400px 로 줄여 저장, 디스크 600개 넘으면 500개로
- **S-08** 바깥으로 여는 모든 곳은 공개 http 검사 하나로
- **S-09** gzip 크기 값은 믿지 않고 32MB 상한
- **S-10** 본문 추출 시 그림·동영상·글꼴 등 불필요한 자원 차단
- **S-11** 추출 스크립트는 페이지와 분리된 공간에서 실행
- **S-12** 받는 크기 상한: 받으면서 세다가 넘으면 그 자리에서 끊고 오류
- **S-13** 끈 출처 글 바로 빼기: 보이는 출처 = 출처 목록에 있고 · 켜져 있고 · 숨기지 않은 것

- **T-03** 번역 캐시

## N. 알림
- **N-01** 맺힘→처짐→떨어짐: 부풂 0.45초, 처짐 0.22초, 중력 2600pt/s², 물방울 반지름 15, 위에 남은 물이 출렁이며 사라짐, 작은 물방울이…
- **N-02** 액체가 이어지는 모양
- **N-03** 물 차오름: 0.75초 동안 아래에서 위로, 두 겹 물결, 좌우 기우뚱, 표면 반짝임 선, 튀는 물방울 4개, 올라오는 거품 5개
- **N-04** 닿는 순간 "똑" 소리, 잔이 살짝 눌렸다 돌아옴
- **N-05** 카드 글자는 물이 30% 찼을 때부터 물과 함께 떠오름
- **N-06** 사진 인화: 카드 오른쪽 58×58 사진이 회색·흐림→선명한 색으로
- **N-07** 머무름 9초, 남은 물이 천천히 빠지는 것으로 표시
- **N-08** 마우스 올림: 닫기 단추, 빠른 단추, 살짝 커지고 그림자 짙어짐
- **N-09** 사라질 때: 카드만 살짝 작아지며 흐려짐
- **N-10** 쌓기: 최대 4장, 여러 건은 0.32초 간격, 3건 넘으면 "새 소식 N건 더" 카드
- **N-11** 위치: 마우스가 있는 화면의 위쪽 가운데
- **N-12** 노치가 있으면 노치에서 검은 물방울
- **N-13** 카드가 없는 곳은 클릭이 뒤 앱으로 통과
- **N-14** 누르면 읽기 창, 다른 앱의 입력 초점을 빼앗지 않음
- **N-15** 미리 보기: 진짜 기사가 아닌 견본 카드, 눌러도 아무 기사도 안 열림
- **N-16** 첫 실행 안내 카드, 직접 확인했는데 없을 때 "새 소식이 없습니다" 카드, 아침 브리핑 카드, 묶음 카드
- **N-17** 움직임 줄이기 설정이면 단순한 나타남·사라짐
- **N-18** 알림 방식: 물방울 / 시스템 알림
- **N-19** 유리 재질: 맥 Liquid Glass
- **N-20** 천장: 맥 = 상단바 아래
- **N-21** 그리기 재질: 맥 = Liquid Glass 물방울
- **N-22** 투명·항상 위·초점 안 뺏기·클릭 통과: 윈도우 = 레이어드 창 +…
- **N-23** 방해하지 않기: 맥 = 방해 금지 시간
- **N-24** 움직임 줄이기: 맥 = 손쉬운 사용 설정, 윈도우 = 애니메이션 효과 끔, 리눅스 = gtk-enable-animations 끔 → 물방울 없이 카드만…
- **N-25** 회의·발표 중 자동 조용히: ① 앞에 있는 다른 앱의 보통 창이 화면 하나를 통째로 덮음 ② 화면 공유·기록 도우미 프로세스가 떠 있음 ③ 캘린더에서 지금…
- **N-26** 분야별 저녁 정리: 모드가 '묶음'인 분야는 묶음을 보낼 때 기기 안 모델이 그 묶음 기사의 원제목·요약만 보고 "오늘 이 분야에서 무슨 일이 · 왜"…
- **N-27** 지켜볼 낱말: 설정 '거르기'에 '지켜볼 낱말'

## R. 읽기 창
- **R-01** 빠른 길: HTML 만 받아 스크립트 없이 Readability 로 추출
- **R-02** 느린 길: 실제로 띄우고 0.6초 뒤부터 0.4초마다 추출 시도, 두 번 같으면 끝, 최대 15초
- **R-03** 블록: 제목·문단·목록·인용·코드·그림·캡션
- **R-04** 원문을 먼저 보여 주고, 첫 8문단+제목 → 나머지 순으로 번역이 바뀜
- **R-05** 번역/원문 전환, 번역이면 원제목 함께
- **R-06** 모양 팝오버: 글자 크기 13~26, 줄 간격, 본문 폭, 바탕, 글꼴, 기본값
- **R-07** 읽는 시간
- **R-08** 머리: 출처 원형·이름·등급 칩·날짜·읽는 시간·번역 방식
- **R-09** 소리 내어 읽기, 창 닫으면 멈춤
- **R-10** 나중에 읽기 단추, 브라우저에서 열기, 공유
- **R-11** 문단 스크랩: 문단에 마우스를 올리면 왼쪽에 ✂︎, 누르면 그 문단 스크랩, 스크랩한 문단은 노란 띠
- **R-12** 실패 화면: 피드 요약 + 까닭별 안내 + 원문 열기 + 제목이 외국어면 "번역된 웹페이지로 보기" + 연결 문제·모름이면 '다시 시도'
- **R-13** 불러오는 동안 글 모양 자리표시
- **R-14** 누른 카드 자리에서 창이 커져 나옴, 여러 창은 24pt 씩 비켜서
- **R-15** 캐시: 메모리 40개, 디스크 150개, 실패는 기억하지 않고 다음에 다시
- **R-16** 알림 뜰 때 상위 3건 미리 준비
- **R-17** 영상·팟캐스트는 읽기 창 대신 원래 앱·브라우저로
- **R-18** 기사 속 사진도 안전 로더
- **R-19** 찾기: ⌘F 찾기 칸, ⌘G / ⇧⌘G 다음·이전, 대소문자·악센트 무시, 보이는 쪽에서
- **R-20** 기사 속 사진 도구: 마우스를 올리면 나오는 단추·오른쪽 클릭으로 사진 속 글자 번역·복사·저장
- **R-21** 본문 다듬기: 기자 이름·이메일 줄은 제목 아래 바이라인으로, 사진 없이 남은 짧은 설명 줄과 표지와 같은 사진·그 설명은 뺌
- **R-22** 표지 사진: 피드 사진 → 매거진 기록 → 기사 머리 og:image

## M. 매거진
- **M-01** 매거진 창: 옆 목록, 여는 동안 작업 표시줄·Dock 에 보임
- **M-02** 기사 DB: items·clusters·issues·scraps 표, 20000건 유지
- **M-03** 편집 점수: 등급 + 1.6·ln + 중요 2.5 + 관심 + 2·exp + 사진 0.4
- **M-04** 호 엮기: 같은 스토리는 대표 하나, 표지, 분야 지면, 구독 채널 지면
- **M-05** 오늘 호·이번 주 호
- **M-06** 머리: DROPCAP 로고·"매거진"·발행 중 표시·호 제목·소식 수·분야 수·정렬 메뉴, 줄이 그어지며 나타남
- **M-07** 표지: 큰 사진 + 켄 번스, 아래 그라데이션, 표지 배지·분야·출처·시간, 큰 제목·원제목, "기사 읽기", 여러 곳이면 "여러 시각 N곳"
- **M-08** 카드: 사진, 영상·팟캐스트는 재생 표시, 종류 배지, 출처·외 N곳·시간·★, 제목 3줄, 읽음 표시, 오른쪽 클릭
- **M-09** 지면이 차례로 깔림, 스크롤할 때 들어오며 또렷해짐
- **M-10** 정렬: 추천순·최신순·많이 보도된 순·출처별
- **M-11** 새 소식이 오면 지면을 갈아엎지 않고 "새 소식이 들어왔어요 · 새로 보기" 띠
- **M-12** 매거진 채우기: 처음 켠 출처·다시 켠 출처·업데이트 뒤 한 번은 확인 때 받은 피드 글 중 최근 7일치를 출처당 120건까지 그날 호에 넣음
- **M-13** 사진 채우기: 사진 없는 최근 3일 기사 12개씩 og:image
- **M-14** 스토리 목록 → 스토리 타임라인
- **M-15** 저장 지면: 카드 격자 + "보관됨" 표시
- **M-16** 검색: 전체 기록에서 제목·출처·요약
- **M-17** 스크랩북: 폴더 칩, 새 폴더, 이름 바꾸기, 기사별 묶음, 인용+원문, 메모 편집, 다른 폴더로 옮기기, 지우기, 처음엔 마지막 쓴 폴더
