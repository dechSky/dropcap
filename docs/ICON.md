## 적용(2단계)

### 도형 원본은 하나: `shared/icon.json`

세 판이 같은 도형 정의를 읽습니다(1단계 문제 5 해결). 좌표는 y 아래로, 패스는 절대 좌표 `M L H V C Z` 만 씁니다(세 판 해석기가 같게 읽도록 — 호·상대 좌표 없음).

| 항목 | 내용 |
|---|---|
| `app` | 1024 격자 앱 아이콘: 824px 둥근 사각형 타일(붉은 주황 그라데이션 + 그림자), 5° 기운 종이 표지·그림자, 남색 제호 띠, 붉은 세리프 D, 글줄 |
| `small` | **32px 이하 단순화 판**: 기울기·표지 그림자·제호 띠를 없애고 표지를 크게, D 를 0.30→0.47 배로 키우고 가로획을 굵게(46→90), 글줄은 굵은 3개 |
| `smallMax` | 32 — 이 크기 이하에서 `small` 을 씀 |
| `symbol` | 16 격자 단색 상징. `read`: 표지 윤곽(굵기 1) 안 D + 글줄 3 + 아랫줄. `unread`: 채운 표지에서 D·글줄이 빠짐(한 패스 evenodd). 16·32px 에서 화소 경계에 맞춤 |

D 는 글꼴이 아니라 직접 그린 패스입니다(라이선스 걱정 없음). 층(layer)마다 `fill`/`opacity` 또는 `gradient`, `evenodd`, `rotate`([도, 중심 x, 중심 y], SVG `rotate()` 와 같음)를 가집니다.

# 1단계 시안(결정 전 기록)

앱 이름은 'Dropcap'(문단 첫 글자를 크게 내려 앉힌 편집 양식)인데 아이콘은 아직 AI 알림 시절의 물방울입니다.
이 문서는 지금 아이콘의 문제와 새 시안 4개를 정리합니다.

견본 PNG 는 저장소 밖 `newsletter-wt/icon-shots/` 에 있습니다(공개 저장소에는 넣지 않음).

| 파일 | 내용 |
|---|---|
| `overview.png` | 지금 + 시안 ①~④ 를 한 장에(위 라이트, 아래 다크) |
| `cN-1024-light.png` · `cN-1024-dark.png` | 시안별 1024px 원본(맥 격자: 1024 캔버스 안 824px 둥근 사각형) |
| `cN-sizes.png` · `cur-sizes.png` | 128·64·32·16px 실제 크기, 32·16px 화소 확대, 상단바 단색 상징(평소·새 소식) — 라이트/다크 바탕 |
| `cN-dock.png` · `cur-dock.png` | 맥 Dock·상단바(라이트/다크 배경화면), 윈도우 작업 표시줄·알림 영역 견본 |

다른 앱 자리는 무늬 없는 색 타일로 채웠습니다(실제 상표 없음).

## 지금 아이콘(물방울)의 문제

1. **정체성이 맞지 않음** — 물방울·물결은 날씨·물·알림 앱으로 읽힙니다. '뉴스 매거진'이나 '드롭캡'이 떠오르지 않습니다.
2. **작은 크기에서 뭉개짐** — 남색 바탕 위 파란 물방울은 명도 차가 작아, 32px 에서 물결 고리·반사광이 사라지고 16px 에서는 파란 얼룩입니다(`cur-sizes.png` 16px×8).
3. **다크 Dock 에서 묻힘** — 거의 검은 남색 타일이라 어두운 Dock·작업 표시줄 바탕과 외곽 대비가 낮습니다(`cur-dock.png` 오른쪽).
4. **상단바·트레이 상징과 모양이 다름** — 맥 상단바는 SF Symbols `newspaper`, 윈도우 트레이·리눅스 상징은 각자 그린 신문 모양이라 앱 아이콘(물방울)과 이어지지 않고, 흔한 신문 그림이라 다른 앱과 구분도 어렵습니다.
5. **세 판이 손으로 옮겨 적은 복사본** — `mac/scripts/make-icon.swift`, `windows/Dropcap.Ui/Toast/AppIcon.cs`, `linux/resources/icons/io.github.dechsky.Dropcap.svg` 가 같은 좌표를 각자 들고 있어(맥은 y 위로, 윈도우·SVG 는 아래로) 고칠 때 어긋나기 쉽습니다.

## 공통 원칙(모든 시안)

- **글자 'D' 는 글꼴이 아니라 직접 그린 패스**입니다(굵은 기둥 + 가는 가로획 + 오른쪽이 두꺼운 둥근 배, 디돈 계열 세리프 느낌). OS 글꼴을 아이콘에 박아 배포하는 라이선스 문제가 없고, 세 판에서 똑같이 나옵니다.
- 도형은 모두 SVG 패스 문자열로 정의 → 2단계에서 맥(CGPath), 윈도우(`SKPath.ParseSvgPathData`), 리눅스(SVG 그대로)가 **같은 문자열**을 쓰게 할 수 있습니다(문제 5 해결).
- 상단바·트레이 상징은 16 격자 단색(템플릿). 평소/새 소식 두 상태는 지금처럼 유지합니다(지금: 빈 신문 ↔ 채운 신문).

## 시안

### ① 드롭캡 D — 큰 세리프 D + 옆과 아래 글줄

종이색 바탕에 남색 D 를 첫 글자처럼 크게, 오른쪽 4줄·아래 2줄의 글줄. 다크 변형은 남색 바탕에 종이색 D.
상징: 굵은 D + 짧은 글줄 3개, 새 소식이면 맨 위 줄 자리에 점.

- 장점: 이름 그대로를 그림으로 보여 줘서 설명이 필요 없음. 밝은 타일이라 다크 Dock 에서 잘 보임. 글 읽는 앱이라는 인상이 가장 분명.
- 단점: 글줄은 32px 이하에서 회색 결로만 남음. 물방울(앱의 알림 기능 흔적)은 사라짐. '문서/메모 앱'과 비슷해 보일 수 있음.

### ② 드롭캡 D + 물방울 — D 의 속(빈 공간)을 파란 물방울로

D 를 타일 가득 크게, 속 공간에 파란 물방울. 기본은 지금과 같은 남색 타일(흰 D), 라이트 변형은 종이색 타일(남색 D).
상징: 굵은 D 안에 물방울 윤곽 — **새 소식이 오면 물방울이 채워짐**(지금의 '카드가 물처럼 차오름' 기능과 같은 은유).

- 장점: 글자 하나라 16px 에서도 D 가 가장 또렷함(`c2-sizes.png`). 지금 아이콘의 남색·파랑·물방울을 이어받아 기존 사용자가 같은 앱으로 알아봄. 상단바 상징의 '물방울 채움'이 이야기가 됨.
- 단점: 글줄이 없어 '드롭캡(문단의 첫 글자)'이라는 편집 양식까지는 덜 전달됨. 남색 기본 타일은 다크 Dock 에서 여전히 어두운 편(흰 D 가 대비를 채움, 라이트 타일을 기본으로 바꾸는 선택지 있음).

### ③ 매거진 표지 — 살짝 기운 종이 표지 위 붉은 첫 글자

붉은 주황 타일 위에 5° 기운 표지(위 제호 띠, 붉은 D, 글줄). 다크 변형은 짙은 고동색 타일.
상징: 표지 윤곽 안의 D + 글줄, 새 소식이면 표지가 채워지고 글자가 빠짐.

- 장점: '매거진'이 가장 직접적. 색이 강해 Dock·작업 표시줄에서 가장 먼저 눈에 띔.
- 단점: 요소가 많아 32px 이하에서 D 가 작아지고 16px 에서는 종이 조각만 보임. 기운 종이·그림자는 맥 최신 평면 양식과 다소 거리가 있음.

### ④ 상자 머리글자 — 붉은 네모 안에 흰 D + 글줄

옛 책의 채색 머리글자처럼 붉은 네모에 D 를 빼고, 오른쪽·아래로 글줄. 라이트(종이)·다크(남색) 변형.
상징: 채운 네모에서 D 를 뺀 모양 + 글줄, 새 소식이면 점.

- 장점: 붉은 네모가 16px 에서도 강한 점으로 남아 찾기 쉬움. 드롭캡 양식이 정확히 보임.
- 단점: 16px 에서는 D 가 붉은 덩어리로 뭉개짐. ①과 구성이 비슷함. 물방울 연결 없음.

## 추천: ②

- 작은 크기(상단바·트레이·16px 목록)에서 가장 잘 읽히고, 상단바 상징의 '물방울이 채워지면 새 소식'이 앱의 물 알림 기능과 맞물립니다.
- 남색·물방울을 이어받아 기존 사용자에게 같은 앱으로 보입니다.

드롭캡 양식을 더 분명히 보여 주고 싶다면 ①이 차선입니다.

## 2단계(결정 뒤) 반영 계획

1. 고른 시안의 도형을 SVG 패스 문자열로 한 곳에 두고, `mac/scripts/make-icon.swift`(CGPath), `windows/tools/IconGen`·`AppIcon.cs`(Skia), `linux/resources/icons/io.github.dechsky.Dropcap.svg` 가 같은 값을 쓰게 맞춤.
2. 상단바·트레이: 맥은 SF Symbols `newspaper` 대신 템플릿 이미지(`isTemplate`)로 교체, 윈도우 `AppIcon.Tray` 와 리눅스 `dropcap-newspaper*-symbolic.svg` 도 같은 상징으로(파일 이름 유지 여부는 그때 결정 — 이름을 바꾸면 리눅스 설치본의 아이콘 캐시·데스크톱 파일을 같이 고쳐야 함).
3. 맥 빌드·설치로 Dock·상단바 확인, 윈도우 .ico 16~256 각 크기 확인.
