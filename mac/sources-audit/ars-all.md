# Ars Technica (`ars-all`)

- 종류: feed · 기본켜짐: 예 · 지금 paywall 값: 없음
- 관찰한 유료 상태: 없음(무료, 광고)
- **판정: 나쁨** — 본문이 광고 칸을 사이에 둔 `.post-content` 여러 덩어리인데, Readability 가 그중 한 덩어리만 골라 2/3 기사에서 앞이나 뒤 절반(문단 3~5개·소제목)이 빠짐.
- 완전성 중앙값(사이트 본문 글 중 앱 본문에 있는 비율): 55% (최저 53%) · 점검일 2026-10-15 · 기사 3건

## 피드로 넘어오는 것

- RSS. 요약 30~90자 + content:encoded 1,400~1,600자(첫 몇 문단 HTML, 전문 아님 — 사이트의 17~54%).
- 사진: media:content 1024~1152px + media:thumbnail 500px(좋음). 분야 4~5개 · 기자 있음 · 날짜 있음.

## 필요한 규칙(제안)

1. Ars 전용: `article .post-content` 를 전부 문서 순서대로 이어 붙여 본문으로(빠른 길에서 Readability 대신).
2. 사진 설명 + "Credit: …" 줄이 문단으로 두 번 나옴 — 설명(cap) 한 번만, 출처는 떼기.
3. 끝 기자 소개 문단(“… is the … Editor at Ars Technica …”) 빼기.
