# MBC 주요뉴스 (`mbc-top`)

- 종류: feed · 기본켜짐: 아니오 · 지금 paywall 값: 없음 → 관찰한 유료 상태: 해당 없음(기사 없음)
- 판정: **나쁨** — 피드가 기사 대신 라디오 시간대 뉴스(mp3)만 줌 — 기사 링크가 없어 앱이 한 건도 못 받음
- 기사 0건 · 완전성(우리/사이트 글자) 중앙값 -% · 사이트 문단 대조 중앙값 -%
- 점검: 2026-10-15, 앱 추출기(ReadSweep 와 같은 `ArticleExtractor.extract(allowScripts: true)`) + 헤드리스 Chromium(본문 상자 선택자는 tools/kr2/sitemeasure.js)

## 피드로 넘어오는 것

- RSS · 항목 20개
- 요약: 길이 중앙값 9자(최대 9) · HTML 든 요약 0/15 · 전문(content:encoded) 중앙값 0자
- 사진: 0/15건에 있음 · 출처 없음
- 날짜 `Thu, 15 Oct 2026 11:00:00 +0900` 꼴 · 분야 0/15 · 기자 칸 0/15 · 링크 꼴 ``

- 항목 20개 모두 'MBC 11시뉴스' 꼴 제목 + `<enclosure type=audio/mpeg>` + guid 만, `<link>` 없음. 요약 9자('MBC 11시뉴스'). 읽기 점검(READSWEEP)에서도 '기사를 주지 않음'과 같은 원인.

## 기사별

| 기사(주소) | 얻은 길 | 우리 글자 / 사이트 글자 (%) | 빠진 것 | 섞인 것 | 사진 | 번역 | 메모 |
|---|---|---|---|---|---|---|---|
| - | - | - | - | - | - | - | 기사를 얻지 못함(위 피드 항목 참고) |

- '우리'는 읽기 창이 실제로 보여 줄 블록 — 추출 결과에서 읽기 창이 숨기는 것(BodyCleanup 의 '이름 기자 메일' 줄·짝 잃은 사진 설명, ImageKey.isJunk 그림)을 뺀 뒤 잼.
- 글자는 공백을 뺀 수. 우리 글자에는 사진 설명·끝 꼬리(저작권 등)가 들어가고, 사이트 글자는 본문 상자 안 보이는 글 전부.
- '문단 대조'는 사이트 본문 상자의 20자 넘는 줄 가운데 앞 25자가 우리 본문에 있는 비율(빠진 것의 척도). '섞인 것'은 우리 블록 가운데 종류 규칙에 걸린 수.
