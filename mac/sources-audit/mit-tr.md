# MIT Technology Review (`mit-tr`)

- 종류: feed · 기본켜짐: 예 · 지금 paywall 값: 없음
- 관찰한 유료 상태: metered(Piano) — HTML·피드에는 전문, 사이트는 스크롤하면 구독 팝업·쿠키 창
- **판정: 좋음** — 3건 모두 100~102%. 부제·날짜·삽화 출처·뉴스레터 권유 몇 줄만 섞임. 피드가 전문을 줌.
- 완전성 중앙값(사이트 본문 글 중 앱 본문에 있는 비율): 100% · 점검일 2026-10-15 · 기사 3건

## 피드로 넘어오는 것

- RSS. 요약 300~370자 + content:encoded 4,400~31,000자 = **전문(사이트의 100%)**. media 없음 → 표지 og:image.
- 분야 2~4개("sponsored" 꼬리표가 붙은 광고성 글도 섞임) · 기자 있음.

## 필요한 규칙(제안)

1. sources.json paywall 값 없음 → `metered` 로(Piano 구독 권유가 뜸).
2. 본문 앞 부제 1줄·날짜 1줄, 끝 "Illustration by …"·"Get the latest updates from MIT Technology Review"·"Discover special offers…" 빼기.
3. 피드 categories 에 "sponsored" 가 있으면 광고성 글 표시.
