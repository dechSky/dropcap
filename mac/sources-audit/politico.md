# Politico (`politico`)

- 종류: feed · 기본켜짐: 아니오 · 지금 paywall 값: 없음
- 관찰한 유료 상태: 일부 기사는 사이트에서도 앞 4문단만(ld isAccessibleForFree=false) — 지금 값 없음
- **판정: 부분** — 뉴스레터(Playbook)는 100%. 일반 기사는 사이트·앱 모두 앞 4문단만 보이는데 **피드 content:encoded 에는 전문(4,358자)이 있음**. 영상 페이지는 앱이 올바르게 실패 처리.
- 완전성 중앙값(사이트 본문 글 중 앱 본문에 있는 비율): 88% · 점검일 2026-10-15 · 기사 3건

## 피드로 넘어오는 것

- RSS. 요약 0~150자 + content:encoded = **전문(일반 기사 4,358자 — 사이트 표시의 3.5배, 뉴스레터 100%)**. 분야 3~7개 · 기자 있음.
- 사진: media 가 Getty 원본 주소(크기 없음, 8MB 넘어 못 받음 — 앱 점검 "피드 사진 못 받음") → og:image 로 대체(READSWEEP 고침대로 동작).
- 점검 도구(node)는 기사 페이지 403(TLS 지문), 앱(URLSession)은 빠른 길 0.2~0.4초 성공.

## 필요한 규칙(제안)

1. 읽기 창: 추린 본문이 피드 content:encoded 보다 훨씬 짧으면(예: 70% 미만) 피드 본문을 블록으로 바꿔 쓰기 — Politico·MIT TR·AWS·New Scientist 일부가 피드로 전문을 줌.
2. paywall 값: 일반 기사가 "앞 4문단 벽"이면 `metered` 표시가 맞음(사용자 확인 필요 — 로그인으로 풀리는지 못 봄).
3. 본문 끝 "Subscribe to the POLITICO Playbook family" 빼기.
